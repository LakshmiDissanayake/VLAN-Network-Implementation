
# VLAN-Network-Implementation

## Overview
This project demonstrates the design and implementation of an enterprise network using Cisco Packet Tracer.

It focuses on VLAN segmentation, VLAN Trunking Protocol (VTP), IEEE 802.1Q trunking, and Inter-VLAN Routing.

## Network Features
- VLAN creation and configuration
- VTP Server, Client, and Transparent modes
- IEEE 802.1Q trunk configuration
- Router-on-a-Stick (ROAS)
- Inter-VLAN communication
- Network connectivity testing

## VLAN Addressing

| Department | VLAN | Network | Gateway |
